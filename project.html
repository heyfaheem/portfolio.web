ChatSphere

A real-time chat app where people join a room with a username and talk instantly, with no page refresh.

Click to read the full details

HTMLCSSJavaScriptNode.jsSocket.io

ABOUT THE PROJECT

ChatSphere is a real-time chat app where people join a room with a username and talk to each other instantly. I built it to understand how live apps like WhatsApp and Discord work behind the scenes, using a small Node.js server and WebSockets to connect users.

FEATURES

  • Join any chat room with your own username
  • Messages appear instantly for everyone in the same room
  • Live typing indicator that shows who is typing
  • Online users list that updates when people join or leave
  • Join and leave notifications in the chat
  • Responsive design for desktop and mobile

TOOLS USED

Node.js, Express, Socket.io, HTML, CSS, JavaScript

WHAT I LEARNED

How WebSockets keep a live connection open between the browser and the server, how to organize users into separate rooms, how to handle events like typing and disconnects, and how to keep user input safe from HTML injection.

HTMLCSSJavaScriptLocalStoragePWA

ABOUT THE PROJECT

StudyBuddy is a productivity web app built on the Pomodoro technique, which splits studying into short focused sessions with small breaks. It needs no account or server, and it can be installed on a phone or computer like a native app.

FEATURES
